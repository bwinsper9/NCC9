
# 🍴 Catering Companion - Final Version

This is the full version of the Catering Companion app with all requested features, defensive coding, and sleek minimalist UI.

## Features
- Multiselect recipe input (autocomplete)
- Number of guests input and scaling
- Consolidated shopping list with unit formatting
- PDF output and on-screen preview of shopping list and recipes
- Defensive handling of missing or malformed data
- Sexy minimalist dark theme for kitchen use

## How to Run
```bash
pip install -r requirements.txt
streamlit run catering_companion.py
```
